# A report of observable-dependent model discrimination

1. **Physical question and alternatives.** State the disputed interaction or
   dynamics, each candidate, initial preparation and which alternatives were omitted.
2. **Measurement record.** Define the observable/event, outcome coding, shot totals,
   rejected outcomes, and whether counts are physical, emulated or synthetic.
3. **Allowed predictions.** Give the reference solver, its numerical checks, all
   error bounds and their evidence. Distinguish an attainable product set from an
   outer box. State shared parameters and lost joint constraints.
4. **Sampling and confidence.** State within-setting assumptions, the fixed family,
   observation alpha, calibration failure budget if supplied, and any data reuse.
5. **Decision.** Report all retained/excluded candidates, witness settings and the
   additive boundary in specified units. Do not rename compatibility as mechanism
   identification, or a candidate-relative survivor as a unique physical truth.
6. **Action.** Separate insufficient statistics, interval overlap and invalid
   calibration assumptions. Report a candidate measurement, tighter bound or
   independent control that would address the diagnosed obstacle.

This is a reporting aid for the specified protocol, not a universal publication
standard or a claim that other valid verification methods must use this software.
