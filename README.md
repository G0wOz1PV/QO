# QO

Reusable tools for quantum dynamics and measurement analysis.

| Project | Purpose |
| --- | --- |
| [QMD](QMD/) | Test candidate predictions against measured counts, calculate error thresholds and compare measurement choices |
| [Electron-gated proton transfer (EGPT)](EGPT/) | Numerical models of electrostatic gating and proton dynamics |

Each project has its own setup instructions and license. The claimcheck examples are artificial inputs for learning the interface.

**Start with [claimcheck's two-command example](QMD/#try-it)** to see which predictions are excluded and how to read the result.
