# Changelog

## 0.2.2

- Shorten the public project directory to QMD (Quantum Model Discrimination).
- Update installation and documentation links; commands and calculations are unchanged.

## 0.2.1

- Run bundled artificial examples with `--demo` from any directory.
- Show confidence intervals and candidate decisions directly in the terminal.
- Make JSON export optional and put decisions first in Markdown reports.
- Shorten the quickstart and explain result labels next to the example.
- Preserve the statistical calculations and existing JSON output structure.

## 0.2.0

- Confidence intervals for independent binary counts and bounded means.
- Candidate exclusion and additive expansion thresholds.
- Pairwise interval diagnostics and prospective measurement selection.
- JSON and Markdown reports with version and input hash.
- Artificial examples and independent probability checks.
